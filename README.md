# Mis Proyectos en Java 🚀

Colección de aplicaciones de escritorio, herramientas y sistemas desarrollados en Java, organizados como un repositorio multiproyecto (monorrepo).

## 📁 Estructura del Repositorio

- **`01-calculadora-desktop/`**: Aplicación de calculadora de escritorio con interfaz gráfica interactiva utilizando **Java Swing**.git

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (JDK 17 o superior)
- **Interfaz Gráfica (GUI):** Java Swing / JavaFX
- **Editor principal:** Cursor
- **Compatibilidad:** Compatible con cualquier IDE Java (NetBeans, BlueJ, VS Code, IntelliJ IDEA).
